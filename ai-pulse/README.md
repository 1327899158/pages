# AI PULSE GitHub Pages frontend

site at `/ai-pulse/`. It embeds the public AI PULSE application so the complete
server-side collection and D1 archive features remain available. GitHub Pages
itself cannot run server code or a database.

- Frontend host: GitHub Pages
- Collection/API/database: Cloudflare Worker + D1
- Complete source branch: `ai-pulse-source`
